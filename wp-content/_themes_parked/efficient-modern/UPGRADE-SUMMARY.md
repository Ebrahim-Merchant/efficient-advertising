## 🎯 Design Philosophy

### Color Scheme
```
Primary Red:   #EF4444  (Vibrant, Modern)
Accent Wine:   #6B1D2D  (Professional, Deep)
Background:    #F9FAFB  (Clean, Light)
Text:          #1F2937  (Readable)
```

### Typography
```
Headings:  Inter Bold/Black (Modern, Clean)
Body:      Inter Regular (Readable)
Accents:   Italic for emphasis
```

### Spacing
- Generous whitespace
- Consistent padding (24px, 48px, 96px)
- Professional margins
- Responsive breakpoints
